# Narrative-driven domain development

1. Author independent canonical episodes and plausible alternatives.
2. Annotate observable events, hidden fictional truth, beliefs with provenance, unresolved hypotheses, commitments, goals, permissions and consequences.
3. Derive candidate mechanisms, typed interfaces and resource lifecycles; use Metis linear logic for generative transitions.
4. Compile and validate against actual Metis tools. Generate traces, retaining seeds, versions and initial state.
5. Narrate traces faithfully and evaluate against independent stories, invariants and real consented interactions.
6. Mine surprises and propose refinements through metis-loop gates; approval precedes deployment.

A surprise can indicate missing evidence, a missing rule, wrong weights, faulty integration or a genuine unexpected event. Do not automatically explain it away. Narrative frequencies are not empirical probabilities; calibrate separately. Distinguish deterministic replay of observations from sampled hypothetical futures.

## Artifact lineage
Every derived case references an immutable source revision and chapter ID. Record observations separately from interpretations. A counterfactual is not an observation. Reserve holdout episodes before extraction and do not expose them to the formalizer.

## Roles
Creative author creates rich stories; formalizer constructs candidate rules; evaluator reports failure modes; human maintainer approves changes. Keep these roles separate even when one model plays several roles.
