# Situations
Sources: B01-C01, C02, C04, C06.
Candidate state: situation(id, type, phase), evidence(source, time), hypothesis(id, explanation, confidence), activity(person, kind), competing goals. Distinguish world events from interpretations.
Transitions: propose, corroborate, contradict, expire, resolve, reopen. Multiple hypotheses can coexist; absence of evidence is not contradiction.
Interfaces: home presence, calendar, commitments, attention, social.
Invariants: presence alone cannot establish concentration; no consequential intervention solely on a speculative psychological inference. Test waking vs turning over, cancelled vs missed appointment, manual override vs device fault.

Status: narrative-derived design brief; not executable or validated Metis syntax.
