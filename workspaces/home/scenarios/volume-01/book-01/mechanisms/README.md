# Shared situations and commitments: a second hypothesis

Source: Book I at `94e2c5829e6ebefa3bd41e35e513bba943dc8e12`, scenes B01-C01-S03, B01-C02-S01/S02, B01-C04-S01/S02, B01-C06-S01/S02/S03, B01-C08-S02 (scene boundaries in the chapter candidate READMEs).

This candidate tests the creative director's question: can the same mechanism handle a manually overridden fan, a cancelled appointment and a corrected pantry belief? `consider` and `accept_report` use data relations to represent all three, retaining the observed discrepancy while accepting a sourced explanation. The accepted report is not a declaration of hidden truth; the other candidate remains an alternative without current acceptance. The pantry scenario is a derived transfer probe, not an independent holdout.

A second mechanism represents promises through scheduled → ready → notified → fulfilled states. Notification is not fulfillment. The trigger can be renegotiated and completion can be reported at each stage. A consented plan survives changed circumstances, which can offer reconsideration but cannot change the plan. Resource `interruption_budget` arbitrates reminders and clarification: one opportunity cannot be spent twice. Two due reminders generate different selections under different seeds; this is an uncalibrated policy experiment, not a justified priority rule.

Human instructions, trusted source identity and interruption opportunities are fixture assumptions. No rule manufactures them. New constants and `alternatives` facts describe instances; rules do not name characters. The model is deliberately small: two alternatives are a simplifying limit, reports can be stale or wrong, and source reliability is not fitted. Reopening a settled issue, cancellation, priority among obligations and contradictory completion reports remain unresolved.

In particular, completion arriving simultaneously with a due trigger can compete with notification. The book's sequential report does not resolve that race. This candidate must not become a reminder runtime without an explicit reconciliation priority/epoch contract. Likewise a stale trigger token can activate a newly rebound promise: event identity and freshness need an architect's decision. These are structural findings, not reasons to pretend the book grants a policy.

This package is a proposal, not an extension of the deployed home composition. Its gates and sampled probes do not constitute human approval.
